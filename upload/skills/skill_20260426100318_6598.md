# 子技能：系统字典查询

## 技能描述
该技能专门处理关于系统字典表（sysdict）的查询，用于获取各类字典项的定义、代码与名称的对应关系。它主要作为基础支撑技能，为其他技能提供字典翻译所需的映射数据，也可以独立查询字典项内容。

## 核心规则
1.  必须隐藏 `id` 主键字段。
2.  当查询特定类型的字典项时（如教育程度），应使用 `code` 字段进行筛选。
3.  输出时应包含字典代码、字典名称、字典值等关键信息，以便理解字典项的完整含义。
4.  字典表中的 `value` 字段存储的是业务表中实际使用的值，`name` 字段是其可读的中文名称。

## 表结构定义
-   **表名：sysdict**
-   **中文名称**：系统字典表
-   **用途描述**：用于存储系统字典数据。数据查询时需要将目标业务表与本表关联，将业务表中存储为字典值的字段用本表的字典名称作为输出项。本数据库中员工的教育程度存储为字典值。
-   **主键**：`id`
-   **外键逻辑**：无

### 字段定义
| 字段名 | 类型        | 是否允许为空 | 默认值 | 注释     | 示例值      |
| :----- | :---------- | :----------- | :----- | :------- | :---------- |
| id     | int         | 否           | -      | 主键ID   | 1           |
| code   | varchar(50) | 是           | NULL   | 字典代码 | 'education' |
| name   | varchar(50) | 是           | NULL   | 字典名称 | '本科'      |
| value  | varchar(50) | 是           | NULL   | 字典值   | '3'         |
| remark | varchar(50) | 是           | NULL   | 备注     | '本科学历'  |

## SQL示例

### 示例1：查询所有教育程度的字典项
```sql
SELECT
    `value` AS `字典值`,
    `name` AS `学历名称`,
    `remark` AS `备注`
FROM `sysdict`
WHERE `code` = 'education'
ORDER BY `value`;
```

### 示例2：根据字典值查询对应的字典名称
```sql
SELECT
    `name` AS `字典名称`
FROM `sysdict`
WHERE `code` = 'education' AND `value` = '03';
```

### 示例3：查询系统中所有的字典类型及其项数
```sql
SELECT
    `code` AS `字典代码`,
    COUNT(*) AS `选项数量`
FROM `sysdict`
GROUP BY `code`
ORDER BY `code`;
```
